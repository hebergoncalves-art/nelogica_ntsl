# Documentação de domínio

Este repositório usa um único contexto. Quando existirem, consulte o `GLOSSARY.md` da raiz e os registros de decisões relevantes em `docs/adr/`. Use os termos do glossário e indique conflitos com decisões existentes antes de propor uma mudança.

Consulte o [Manual NTSL da Nelogica](https://downloadserver-cdn.nelogica.com.br/content/profit/manual_ntsl/ManualNTSL.pdf) para comportamento da linguagem e assinaturas de funções. Registre na spec a versão ou o módulo do Profit quando houver dependência.
